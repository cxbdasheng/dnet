在 ZeroSSL 控制台获取 ACME EAB 凭据，不是 API Access Key。编辑时留空保留已保存密钥。
证书机构必须通过公网 TCP 80 访问验证服务。请将外部 80 映射到此端口，或通过现有 Web 服务器转发 /.well-known/acme-challenge/ 路径。该监听仅在申请期间启动，不能占用现有 DWS 端口。HTTP 验证不支持通配符域名。
凭据需具备所选区域的 DNS 记录创建和删除权限。阿里云、腾讯云填写与 DDNS 相同类型的云账户密钥即可，主域名默认自动确定。Cloudflare 需同时授权 Zone Read（区域读取）和 DNS Edit（DNS 编辑），区域由程序自动查询。编辑时密钥留空保留原值，切换厂商需重新填写。
短期证书的提前量最多为有效期的三分之一。失败后自动重试间隔至少 6 小时。
